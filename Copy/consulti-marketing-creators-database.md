# Consulti — Creator Database Campaign

**Target:** Marketing agencies and PR companies
**Bison campaign:** `Marketing - Creators Data Base (7/26)` (ID 1008)
**Structure:** 3 emails · 4 variants on E1 · 2 variants each on E2 and E3
**Cadence:** Day 1 → wait 2 → wait 3 · plain text ON · open tracking OFF

---

## What we're offering

Consulti is a **self-serve lead data platform** — you filter by niche and pull the lists yourself, no done-for-you service.

For this campaign we lead with the **creator database**: 847k creators across YouTube and podcasts, with contact details attached. Positioning is contact data agencies and PR teams can't get elsewhere, since most creator tools return a channel name and follower count but no way to actually reach the person.

## Lead magnets

1. **No cost sample list** built for their niche (primary ask across E1)
2. **Prebuilt B2B decision-maker lists** at `consulti.ai/free-leads`, yours to download, no signup (E2). Note: this page is **B2B only, no creator data** — do not describe it as creator lists.
3. **Gifted month of pro** so they can pull their own (PS on every E1, and E3)

## Copy rule

Avoid **"free"**, **"no cost"**, **"compare"**, and **"offer"** (as a noun). All four are flagged by the Mailmeteor spam checker — "free"/"no cost"/"compare" land in the **shady** category (+21 each, instant Poor) and "offer" in **money** (+20).

Verified replacements that score clean:

| Instead of | Use |
|---|---|
| `free` / `no cost` | `on us`, `at no charge`, or drop it |
| `compare it against` | `put it next to` |
| `pro access` | `a month of pro` |
| `the offer stands` | `still happy to help` |
| `not a trial` | `nothing owed` |

Note: an earlier version of this doc said to swap "free" for "no cost". That was wrong — both score identically as shady. The `/free-leads` URL is fine since links are not scored as prose.

## CTA rule

Every email ends on a **yes / interested question**. E3·V1 deliberately withholds the gift link so interest converts into a tracked reply instead of a silent click.

## Pairing

- **E2·V1 → E3·V1** — prebuilt lists, then gifted access (escalating gives)
- **E2·V2 → E3·V2** — insight, then the standing offer

## Pre-launch checklist

1. Flip **plain text ON** in the Bison UI (the API cannot set it)
2. `consulti.ai/free-leads` is B2B only. Copy reflects this — never promise creator lists at that URL.
3. Attach the lead list, then unpause
4. Mailboxes: use only vetted senders (Connected, warmup on, warmup score 75+, bounce under 3%)
